Flows

A flow connects triggers (a datastream value, an alarm, a device, a schedule, a webhook) through logic (conditions, switches, math, delays, aggregation, latches) to actions (store a value, send a command, notify, open an incident, call a URL). Flows run on the server all the time; every action is audited with the flow and its version. Computation uses expressions only.
