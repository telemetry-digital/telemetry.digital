Branding and theme

Logo, colours and font apply to every page and to PDF reports. The product footer (ctrl32 · telemetry, GitHub, license) is fixed; only a licensed white label (below) replaces it.

Map tiles

Raster XYZ tiles for map widgets and device positions. Empty = built-in OpenStreetMap tiles, which their policy allows for light use only; for regular use enter your own tile server or a provider with a key (MapTiler, Stadia, Thunderforest…).
A self-hosted map archive (PMTiles, set in config.toml under [map]) is used when the URL is empty, so maps work without the Internet.

White label

Your own product name, footer and browser icon instead of ctrl32 telemetry — on every page, the installed app, e-mails, authenticator apps and PDF reports.

White labeling is a paid feature. Install a license under System → License; until then the settings can be prepared but are not applied.

Notification channels

  
Channels

    
Where alarms are delivered: e-mail recipients, an HTTP webhook signed with HMAC-SHA256, a generic HTTP SMS gateway, a voice call through an HTTP provider, or Web Push to the browsers of named users (each user enables it under My account → Browser notifications). Steps in minutes after the alarm: step 0 at once, later steps only while the alarm is still active and unacknowledged; clearing sends a notice to the step-0 channels. Assign a policy to an alarm rule on the datastream.

Security policy

  

    

      
Rules of this organization for commands and control.

      
      
When on, every command (setpoint, switch, button, connector write) waits until a different user with the device.command permission approves it. The approval is recorded in the audit trail.

      
      
New alarm rule versions and rule disabling become change requests that a different user with config.write approves under Settings → Approvals.

      
      
Assigning or removing a datastream on a device becomes a change request that a different user with device.manage approves.

      
      
A technician's VPN access becomes active only after a different user with vpn.manage or system.admin approves a time-limited access grant under Settings → Approvals. New technicians are added disabled. Requires the license for time-limited access.

      
      

      

    

  





  
AI assistants

  

    
AI assistants connect over MCP (Model Context Protocol) and can do everything this application offers — with the permissions of the user who approves them, never more. Every change carries a reason and goes to the audit trail with the note “via MCP”. Camera sound, unmasked pictures and evidence need their own permissions, as in the web UI.
