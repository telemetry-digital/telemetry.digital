VPN

Technicians reach PLCs and HMIs at sites, routers connect whole site networks, devices send data through the tunnel. The server is the hub; peers reach nothing until an access rule allows it.

Four eyes for VPN access is on. A technician's access starts only when a different person approves a time-limited grant (Settings → Approvals). New technicians are added disabled.

Server

Windows: the VPN runs inside the server agent (userspace WireGuard). The access rules are enforced there; services of this server are reached through 127.0.0.1, UDP services of the server and connections from the server into sites are not available.

License

Free: up to 5 peers (devices and technicians). With the license: unlimited peers, sites with routed subnets (site-to-site) and time-limited or approved access for technicians. Without the license existing peers keep working.
