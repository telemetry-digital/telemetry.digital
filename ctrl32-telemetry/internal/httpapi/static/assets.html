Automation

Rules

Condition → action over any datastreams: when all (or any) of the conditions hold — optionally for a hold time — the rule fires its actions: notify a channel, call a webhook, send a device command, raise an alarm or write a derived datastream. When the condition ends, the exit actions run and alarms raised by the rule are cleared. Rules that send commands need a second person's approval when the four-eyes policy is on.
