Dashboards

A dashboard is a screen of widgets placed on a 12-column grid: trends, latest values, gauges, state indicators, tables, alarms, devices and a map. A process picture is a SCADA screen drawn in the editor — vessels, pumps, valves, pipes, instruments and texts that move with live values — optionally with widgets on top. Every save is a new version with a reason. The default screen opens on the home page.
