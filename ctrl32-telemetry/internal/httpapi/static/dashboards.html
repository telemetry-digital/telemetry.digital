Dashboards

A dashboard is a screen of widgets placed on a 12-column grid: trends, latest values, gauges, state indicators, tables, alarms, devices and a map. A process picture is a SCADA screen drawn in the editor — vessels, pumps, valves, pipes, instruments and texts that move with live values — optionally with widgets on top. Every save is a new version with a reason. The default screen opens on the home page.

Dashboard settings

A bar on top of the dashboard: widgets that follow the dashboard filters show only what matches the chosen values. The values chosen in the filter bar of the editor are saved as the defaults. Public: viewers of the public link may change the filter; otherwise its default applies there. A value filter is a number or a text viewers type, such as a temperature limit, which key filters compare with.
An entity alias is a named set of devices, assets, datastreams or sites that many widgets share — for example all fridges, everything under one building, or the entity chosen by a click (the current entity of a dashboard state). Widgets take their data from an alias on their Data tab; new devices appear on their own.
A key filter keeps the entities whose latest values, attributes, quality, age or alarm state meet its conditions — for example temperature above 8 °C, or above the limit stored in an attribute of each fridge. Attach it to the alias of a widget (Data tab) to show only the matching entities, or highlight the matching rows of a table.
Organization attributes
Values every key filter can compare with (attribute of the organization), one per line as name = value.
States are views of one dashboard, such as Overview and Device detail. The first state is the main view; widget actions (a click on a table row, a map marker or a chart) open another state with the clicked entity, which the aliases of kind Current entity show. The editor shows one state at a time (tabs above the grid).
Anyone with the link sees this dashboard read-only, without signing in — only the data its widgets bind and its aliases select. Regenerating invalidates the old link.
