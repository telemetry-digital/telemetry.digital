Backups

  

  

    

      
State

      

      
A backup bundles the database dump (pg_dump), the configuration with its secrets, and the proxy and VPN state, with a manifest and a checksum. Keep a copy away from this server: set an offsite target below. Restore instructions are inside the bundle (RESTORE.txt).

    

    

      
Daily schedule

      

        
        
        

          
          
          
        

        
The newest daily backups, plus the newest backup of each of the last weeks and months (grandfather–father–son). The same rule applies at the offsite target.

        
        
        
        

        

      

    

  

  

    

      
Offsite copy

      
After every backup the encrypted bundle and its checksum go to this target and are read back; a copy counts only when it matches. Unencrypted backups never leave the server. At the target only the backups of this server are ever deleted.

      

        
        

        

          

          

          
          
          
        

        

          
          

          

          
          
        

        
        

        

        

      

    

    

      
Restore test

      
The newest backup — from the offsite target when one is set — is checked against its checksum, decrypted, checked against its manifest, restored into a temporary database and compared with the figures it recorded. The live database is never touched. A failure opens an incident.

Redundant database

  

    
This server

    
Functions

      

        
One-time copy
Copy the live database to another PC, then detach it safely: verified, complete, independent (archive, move, test system).

        
Continuous replica
A read-only copy at another site that follows every change within seconds; incident when it falls behind or disconnects.

        
Hot standby
A complete server ready to take over; promoted manually on the standby when the primary fails; the old primary then refuses writes.

      

      
A replica is not a backup: deleted or damaged data is copied too. Keep the backups.

Update mode

      

        
        
        
        

          

            
            
          

          
          
          
        

        
        
        

        

      

    

  

  

    

      
Install from the distribution point

      

        
        
        
        
Only a release signed with a key built into this version is installed; every file must match the signed manifest. When the new version does not answer healthy after the restart, the previous one returns automatically.

        
With a licence, versions released after the updates included in the licence ended are not installed; the running system is not changed. Without a licence every version can be installed.

        

        

        

      

    

    

      
Upload package

      
For servers without the Internet: the offline package of a release (ctrl32-telemetry-VERSION-offline.zip from the download page). The agent verifies its signature and every file before anything is kept, then installs it like an online update. Detector parts in the package serve the object counting detector installation.

License

  

    
ctrl32 telemetry is free, including up to 4 cameras. A licence for this server covers more than 4 cameras, white labeling, changes through AI assistants and the VPN extras (more than 5 peers, sites, time-limited and approved access for technicians).

    
The licence includes updates for its period. After that the system keeps running with everything it has; only newer versions are not installed until the licence is renewed.

    

    

    

  

  

    
Activate with the order number

    
One ctrl32 licence unlocks either the ctrl32 editor or the licensed features of one server, not both.

    
Enter the order number from the purchase confirmation. This server sends it with its name to the licence service and installs the license it gets. For the first 14 days (the refund period) the license runs 30 days and renews itself; after that the license without an expiry date arrives on its own.
