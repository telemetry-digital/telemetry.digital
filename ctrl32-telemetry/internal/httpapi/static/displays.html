Displays

A display is a screen at a wall — a PC, a mini-PC or a smart TV with a browser — that shows dashboards, process screens and video walls in turn, without anyone signed in. It shows only what it is given, changes nothing and can be disconnected at any time. Cameras with an event can enlarge themselves on it, and an operator can send a camera to it.

Setting up a display computer

  1. On the computer at the wall open in Chrome or Edge — it shows a code.
  2. Here choose Pair display, enter the code, name the display and choose what it shows.
  3. For permanent use start the browser in kiosk mode when the computer starts, for example chrome --kiosk --autoplay-policy=no-user-gesture-required (Windows: a shortcut in the Startup folder; Linux or Raspberry Pi: an autostart entry). The display stays paired over restarts.
  4. Each display computer decodes its own video: for 20 camera tiles a mini-PC with Intel graphics is enough; the server only forwards the streams.
